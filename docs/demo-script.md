# SolanaLens Demo Script

Use this English script for a concise hackathon recording. Keep the browser at
100% zoom, hide bookmarks and personal tabs, and use a dedicated test wallet.

## 0:00–0:15 — Opening

**On screen:** SolanaLens overview and ecosystem pulse.

**Narration:**

> Crypto charts show what moved, but rarely what the market expects next.
> SolanaLens combines live Solana asset data with Panta prediction-market
> probabilities, turning real-world expectations into transparent event-risk
> intelligence.

## 0:15–0:35 — Asset and event intelligence

**On screen:** Asset Lens, score methodology, then Event Radar.

**Narration:**

> The terminal tracks SOL, JUP, JTO, and PYTH price, volume, and liquidity. Each
> event score is explainable: 50 percent Panta probability, 30 percent asset
> momentum, and 20 percent liquidity quality. Select an event to see its YES and
> NO prices, related assets, volume, and the change in market conviction.

## 0:35–0:48 — Watchlist

**On screen:** Select “Watch probability ±5 pts,” then open the bell drawer.

**Narration:**

> A trader can save an event locally and see when its probability moves five
> points from the starting level. This keeps event risk connected to the asset
> research workflow.

## 0:48–1:15 — Panta execution

**On screen:** Connect the test wallet, choose YES or NO, enter an amount, show
the live quote, and proceed to wallet approval.

**Narration:**

> Panta powers the execution path. SolanaLens requests a live primary-market
> quote, asks Panta to build the transaction, and sends the unsigned
> instructions to the connected wallet. The wallet signs locally; SolanaLens
> broadcasts on Solana, then submits, verifies, and attributes the trade through
> Panta. The API key and private wallet material never enter the browser.

## 1:15–1:28 — Positions and claims

**On screen:** Portfolio, position rows, claimable status, and claim action.

**Narration:**

> The same product reads wallet positions, identifies eligible winnings, and
> builds a non-custodial claim transaction for the user to approve.

## 1:28–1:40 — Close

**On screen:** Return to the overview, then briefly show the architecture image.

**Narration:**

> SolanaLens makes Panta useful beyond a prediction-market destination. It is an
> event-intelligence and execution layer for the Solana ecosystem.

## Recording checklist

- Use English narration and captions.
- Show the live-data badge and the connected test-wallet state.
- Keep the final transaction link visible long enough to verify.
- Do not display API keys, seed phrases, browser password prompts, or balances
  from a personal wallet.
- If a live request fails, record the failure honestly; never present demo data
  as a successful live trade.
- Export a landscape video and verify that text remains readable on mobile.
